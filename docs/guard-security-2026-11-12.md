# Guard and security pass — Windows

Godot owns perception, reachable routes, spaced and exclusive guard posts, and ladder reservations. Qwen chooses immediate cover from eligible nearby guards. Jev proposes a later perimeter expansion using reachable approaches. Replies are checked against the current incident and current guard availability before application. Neither model receives a hidden live player location.

Start with `Start Miro.ps1`. It prewarms the local Ollama `qwen3:0.6b` model and enables both integrations. Jev reads `JEV_API_KEY` (or `TYPESAFE_API_KEY`) from the environment or a private `.env` beside the launcher. No key is included in the build. Logs report readiness, requests, accepted assignments, failures and stale results. Godot continues assigning jobs when either service is unavailable.

Security uses the existing authenticated terminal connection and MP3 range. MP3 offers `cameras hack` and `turrets hack`; terminal/service consoles offer `cameras watch`. Both surfaces support `cameras on/off` and `turrets on/off`. Commands affect surviving devices on Miro's storey. Camera viewing uses W/S to cycle and E/Escape to exit. Miro stays vulnerable at his real position and loses the feed when the connection drops. Turret override lasts 1.5 seconds with a shared 10-second cooldown, sees guards farther away, and can still shoot Miro. Niro retains his damage rules.

Guard changes cover turning cooldowns, blocked ladder recovery, shot reactions, same-storey hearing of ceiling camera impacts, and corpse visibility. Checkpoints capture a coherent snapshot; later deaths and security changes do not rewrite older snapshots. Vents require earlier mandatory objectives. Retry concealment lasts two seconds and attacks cancel it.

The visual pass removes the starting-cell vent, shifts the middle prison vent, checks support under both furniture feet, clears windows and vents of background fixtures, separates containment tanks from interactive props, and removes Level 3's fourth-storey far-left turret. Game-rendered audit images are generated by `tools/run_security_visual_audit.py`.

Validation includes targeted security/guard/vent tests, actual Qwen and Jev requests, ladder and spacing regressions, a 120-entry scene retry soak, the full level checks, and a QA exported five-level route. The route uses a health buffer to test traversal and progression; it is not a difficulty or balance measurement.
